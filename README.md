# DUNIA TKJ | Kelompok 4

Projek KKA (Kecerdasan Koding Artifisial)
Kelas X TKJ 2 - Teknik Komputer Jaringan SMKN 2 Banjar

## Isi website
- Judul DUNIA TKJ dengan logo SMKN 2 Banjar dan logo TKJ (background logo sudah dihapus).
- Latar belakang gradasi biru dan kuning, dengan animasi jaringan di bagian atas.
- Menu: Beranda, Materi, Tentang, dan Ringkasan Materi.
- 5 materi: Komputer Jaringan, Profesi TKJ, Cloud Computing, Internet of Things, Smart School.
- Setiap materi punya tombol Materi (artikel) dan Video (YouTube).

## File
- `index.html` : file utama (HTML, CSS, JavaScript, dan logo jadi satu)
- `vercel.json` : pengaturan hosting di Vercel
- `README.md` : penjelasan projek

## Cara menjalankan
Buka `index.html` menggunakan browser (Chrome, Edge, Firefox, atau browser lainnya).

## Cara mengubah materi
Buka `index.html`, cari bagian `const topics = [...]`, lalu ubah judul, deskripsi, atau link-nya.
